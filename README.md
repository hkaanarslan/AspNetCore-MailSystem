
# 📬 AspNetCore Mail System

Modern bir mail yönetim sistemi projesidir.  
ASP.NET Core MVC ve Identity kullanılarak geliştirilmiştir.

---

## 🚀 Proje Hakkında

Bu proje kullanıcıların:

- ✅ Kayıt olabilmesini
- ✅ Email doğrulaması yapabilmesini
- ✅ Giriş yapabilmesini
- ✅ Mesaj gönderip alabilmesini
- ✅ Taslak kaydedebilmesini
- ✅ Mesajları yıldızlayabilmesini
- ✅ Mesajları kategorilere ayırabilmesini
- ✅ Silinenler kutusuna taşıyabilmesini
- ✅ Kalıcı silme (Hard Delete) yapabilmesini
- ✅ Profil düzenleyebilmesini

sağlayan bir mail sistemidir.

---

## 🛠️ Kullanılan Teknolojiler

- ASP.NET Core MVC
- Entity Framework Core
- ASP.NET Core Identity
- SQL Server
- MailKit (SMTP Email Gönderimi)
- Bootstrap
- JavaScript (AJAX işlemleri)

---

## 🔐 Özellikler

### 👤 Kullanıcı Sistemi
- Identity ile güvenli kullanıcı yönetimi
- Şifre kuralları
- Email doğrulama sistemi
- Profil güncelleme
- Şifre değiştirme

### 📥 Mesaj Sistemi
- Gelen Kutusu
- Gönderilenler
- Taslaklar
- Yıldızlı Mesajlar
- Silinenler (Soft Delete)
- Kalıcı Silme (Hard Delete)
- Çoklu Silme (AJAX)
- Mesaj Detay Görüntüleme
- Yanıt Verme (Reply)

### 📊 Dashboard
- Mesaj istatistikleri
- Son mesajlar
- Kategori bazlı grafik

---

## 🧠 Öğrenilen Konular

Bu proje ile:

- Identity yapısı
- Role ve kullanıcı yönetimi
- SMTP ile email gönderimi
- Soft Delete mantığı
- AJAX ile veri işlemleri
- MVC mimarisi
- ViewModel kullanımı

konularında pratik yapılmıştır.
